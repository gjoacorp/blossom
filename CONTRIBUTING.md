# Contributing 

## How to contribute

1. Identify an issue with **blossom** that you'd like to address. This can be something small, like fixing a typo, or something more ambitious like adding a new feature.
2. Create a GitHub issue that includes a description of the issue that you've identified and how you plan to address it. This is also an opportunity for other contributors to weigh-in by offering feedback/advice.
3. Implement your changes.
4. When ready, create a pull request (PR) that includes an overview of what you've changed in its description. You should also provide evidence that all tests passed on your machine.
5. Request a code review.
6. Engage with the reviewer and take into account their suggestions. If all is well, your PR will be merged and you can call yourself a contributor.

## Best practices

- Write code that balances being succinct, performant, and readable.
- Write modern (C++20 or later) C++.
- If you've added something that is testable, write a test.
